# MYP 语言语法设计模板

> 请逐项填写或修改你的选择，完成后发回给我。

---

## 1️⃣ 基础词法

| 项目 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 单行注释 | `// 注释` | |
| 多行注释 | `/* 注释 */` | |
| 语句结束符 | `;` 分号 | |
| 标识符规则 | 字母/下划线开头 + 字母/数字/下划线 | |
| 关键字列表 | `var`, `func`, `class`, `if`, `else`, `while`, `for`, `return`, `break`, `continue`, `true`, `false`, `null`, `this`, `super`, `new`, `extends`, `implements`, `interface`, `import`, `void` | |

## 2️⃣ 字面量

| 类型 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 整型 | `42`, `0xFF` | |
| 浮点 | `3.14`, `1.0e-5` | |
| 布尔 | `true` / `false` | |
| 字符串 | `"hello"`（双引号） | |
| 空值 | `null` | |

## 3️⃣ 变量声明

| 项目 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 关键字 | `var x: int = 5` | |
| 类型位置 | 后置 `x: int` | |
| 类型推断 | 支持 `var x = 42` | |
| 可变性 | 一律可变（不区分 var/let） | |

## 4️⃣ 函数

| 项目 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 关键字 | `func add(a: int, b: int): int` | |
| 参数语法 | `a: int`（类型后置） | |
| 返回类型 | `: int` 后置 | |
| 无返回值 | `: void` | |
| 默认参数 | 第一版不支持 | |
| 入口函数 | `func main(): void` | |

## 5️⃣ 控制流

| 结构 | 推荐方案 | ⬅️ 你的决定/修改 |
|------|---------|----------------|
| if | `if (cond) { ... } else { ... }` | |
| while | `while (cond) { ... }` | |
| for | `for (init; cond; step) { ... }` | |
| for-each | 第一版不支持 | |
| break | `break;` | |
| continue | `continue;` | |
| return | `return expr;` | |
| 条件括号 | 必须带 `()` | |

## 6️⃣ 面向对象

| 项目 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 类关键字 | `class` | |
| 继承 | `class Dog extends Animal` | |
| 实现接口 | `class Bird implements Flyable` | |
| 构造函数 | `func init()` | |
| 访问控制 | 全部公开（无 private/public） | |
| this/super | `this.field`, `super.method()` | |
| 成员操作符 | `.` 点号 | |
| 接口关键字 | `interface` | |

## 7️⃣ 表达式

| 运算符 | 推荐方案 | ⬅️ 你的决定/修改 |
|--------|---------|----------------|
| 算术 | `+`, `-`, `*`, `/`, `%` | |
| 比较 | `==`, `!=`, `<`, `>`, `<=`, `>=` | |
| 逻辑 | `&&`, `\|\|`, `!` | |
| 赋值 | `=`（不支持复合赋值） | |
| 自增/减 | 不支持 `++`/`--` | |
| 三元 | 不支持 `?:` | |
| 下标 | `arr[i]` | |
| 调用 | `func(args)` | |
| 对象创建 | `new ClassName(args)` | |

## 8️⃣ 类型系统

| 项目 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 基本类型 | `int`, `float`, `bool`, `string` | |
| int 位数 | 32-bit | |
| float 位数 | 64-bit (double) | |
| 数组语法 | `int[]` | |
| 泛型 | 第一版不支持 | |

## 9️⃣ 模块与导入

| 项目 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 导入语法 | `import "filename.myp";` | |
| 命名空间 | 扁平结构 | |

## 🔟 其他

| 项目 | 推荐方案 | ⬅️ 你的决定 |
|------|---------|------------|
| 文件扩展名 | `.myp` | |
| Lambda/闭包 | 第一版不支持 | |
| 枚举 | 第一版不支持 | |
| 运算符重载 | 支持（v2.4.1+：struct `operator:` 节 + 顶层 `@op("+")` 函数） | |
